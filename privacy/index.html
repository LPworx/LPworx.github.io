LP eBay Seller Privacy Policy

Effective date: November 21, 2026.

LP eBay Seller is a private tool used only by its owner, Luke Peck, to track his own eBay sales.

It stores the owner’s own eBay orders, sale amounts, eBay fees, ad fees, shipping label costs, and item costs. It stores no buyer names, addresses, emails, or phone numbers.

The data is stored in a private Cloudflare database. The eBay sign-in token is encrypted.

The app does not sell, share, or publish any data. It does not use eBay data to train AI.

Data is deleted when it is no longer needed, when eBay or the user asks, or when the app stops using eBay’s APIs. eBay account deletion notices are honored.

Contact: privacy@lpworx.com
